# deal-board-app

Static shell of the Deal Board PWA (one row per wait: waiting on / for / blocks).

No data lives here. Data sits in a private database behind Row Level Security and an owner login. The key in `index.html` is a publishable key and is meant to be public.

Specs, migrations and the skill file live in the private `deal-board` repo.
